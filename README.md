# DT-S Spa & Wellness

A responsive static website concept for a spa and massage business in Kampala, Uganda.

## Pages
- `index.html` — homepage, treatment descriptions and appointment enquiry form.
- `about us.html` — about the spa.
- `gallery.html` — original image, audio and video assets.
- `contact us.html` — contact information and location.
- `examples.html` — preserved HTML tables, lists and form examples from the original website.

## Run locally
Open `index.html` in a modern browser. The site uses plain HTML, CSS and JavaScript and does not require a build step.

## Booking behaviour
The appointment form prepares a WhatsApp message for the visitor to review and send. It does not store information, confirm appointments or connect to a database. Confirm the destination number and the existing contact details before public launch.

## Before publishing
Review every retained photo and media file, verify all business details, and replace any image that does not accurately represent the current spa. The tables, lists, form demonstration and media assets have been retained in the project rather than mixed into the main customer-facing sections.
